製作流程:首先建立一個 3D 專案，並用內建的 3D 物件拉出所需的物件，並建
立 Apple 和 Bomb 的 prefab，接著再用 C#寫出導演腳本、生成腳本、籃子和
掉落物的腳本並掛上，最後再加上 UI。

關卡設計: 有三個階段
第一階段: 二十秒 掉落速度 3.5 產生速度 0.9 蘋果炸彈 9:1 接到蘋果+30 分
接到炸彈-20 分 本階段是讓玩家熟悉操作 故玩起來進度會比較緩慢
第二階段: 五十秒 掉落速度 5 產生速度 0.45 蘋果炸彈 3:7 接到蘋果+30 分
接到炸彈-50 分 這階段是玩家主要累積分數的階段 佔遊戲大部分時長
第三階段: 二十秒 掉落速度 12 產生速度 0.25 蘋果炸彈 0:1 接到炸彈分數砍
半 最後階段主要是讓玩家去專注躲避 因此沒有蘋果
